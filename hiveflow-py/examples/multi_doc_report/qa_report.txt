CRITICAL BUGS FOUND

BUG-1847: Offline sync drops records when device storage exceeds 400MB
Severity: P1
Status: Fixed in build 14.3.2
Steps to reproduce:
  1. Enable airplane mode
  2. Create 500+ inspection records with photos
  3. Restore connectivity
  4. Observe sync progress
Expected: All records sync successfully
Actual: Records created after 400MB threshold are silently dropped
Root cause: SQLite WAL checkpoint triggered during sync, conflicting with
  insert operations. Fixed by deferring WAL checkpoint until sync completes.

BUG-1852: GPS track recording stops after 4 hours in background on iOS
Severity: P2
Status: Open (assigned to David, Sprint 15)
Steps to reproduce:
  1. Start track recording
  2. Switch to another app
  3. Wait 4+ hours
Expected: Continuous track recording
Actual: Recording stops at approximately 4 hours
Root cause: iOS background task expiration. Need to use location-based
  background mode instead of generic background task.
